# Одна кухня, три света

Страница-переключатель освещения: три снимка одной кухни сведены в общую рамку,
так что при переключении меняется только свет, а композиция стоит на месте.

```
source/          исходные снимки (day / sunset / evening)
images/          сведённые кадры, 1360×1020 и 680×510, WebP
tools/align.py   сведение серии в общий кадр
tools/make_artifact.py  сборка фрагмента для публикации в Artifacts
index.html       страница
```

## Как сведены кадры

Снимки сделаны с чуть разных точек, поэтому «в лоб» переключать их нельзя —
прыгает вся композиция. `tools/align.py` делает следующее:

1. Ищет SIFT-признаки и считает гомографию каждого кадра к опорному. Перебирает
   пороги матчинга и RANSAC, выбирает вариант с лучшим NCC — сравнение идёт на
   картинках с локально нормализованной яркостью, чтобы разница освещения
   не влияла на оценку совпадения.
2. Опорный кадр выбирает сам: тот, к которому остальные ложатся лучше всего
   по сумме NCC. На текущей серии это `evening`.
3. Проецирует все кадры в систему координат опорного и ищет наибольший
   вписанный прямоугольник 4:3, целиком лежащий внутри валидной области всех
   кадров (бинарный поиск по ширине + интегральное изображение).

Результат на текущей серии: кроп 1371×1028, то есть 88% исходного поля;
NCC между кадрами 0,37–0,53 при 0,32–0,52 до сведения.

### Почему без нежёсткой деформации

Доведение оптическим потоком (`cv2.DISOpticalFlow`) поднимает NCC до 0,62–0,68,
но выгибает прямые линии фасадов — на глянцевой кухне «резиновые» края видно
сразу. Поэтому оставлена только строгая проекция: геометрия честная, а остаточные
расхождения приходятся на места, где снимки действительно различаются по
содержанию (полки за стеклом, раскладка высокого шкафа).

## Пересобрать

```sh
pip install opencv-python-headless
python3 tools/align.py source images
```

Скрипт берёт все `*.webp`, `*.jpg` и `*.png` из `source/`, имена файлов
становятся именами результатов. Настройки — константы в начале `align.py`:
`ASPECT`, `LONG_SIDE`, `WIDTHS`, `QUALITY`.

## Добавить кадр

Положить снимок в `source/` под понятным именем, прогнать `align.py`, затем
дописать состояние в массив `STATES` в `index.html` и добавить соответствующий
`<img id="shot-…">` в блок `.stage`. Остальное (кнопка, шкала, подпись,
клавиатура) строится из `STATES` само.

## Страница

Открывается как статика — `index.html` рядом с папкой `images/`, без сборки.
Переключение: клик по состоянию, стрелки `←` `→`, цифры `1`–`3`.
Кнопка «Прогнать свет» гоняет состояния по кругу.
