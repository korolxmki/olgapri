# Мебель на заказ — лендинг

Одностраничный сайт для мастерской встроенной мебели. Собран по спецификации
из `10k_prompt.pdf`: один self-contained HTML-файл, весь CSS и JS внутри,
снаружи — только CDN-библиотеки.

## Файлы

| Путь | Что это |
|---|---|
| `index.html` | **Готовый сайт.** Фото зашиты как data-URI, открывается двойным кликом |
| `src/template.html` | Шаблон с токенами `{{HERO_BG}}` и т.п. — здесь правим вёрстку и тексты |
| `assets/*.jpg` | Четыре фото работ, пережатые под веб |
| `build.py` | Подставляет фото из `assets/` в шаблон и собирает `index.html` |

## Сборка

```bash
python3 build.py
```

Меняем `src/template.html` или файлы в `assets/`, запускаем `build.py` — `index.html` пересобирается.

## Техстек

Подключается с CDN, поэтому для полного вида нужен интернет. Без него сайт
всё равно читается: фото зашиты внутрь, у всех фоновых картинок есть
градиентные фоллбеки.

GSAP 3.12 · AOS 2.3 · Splitting.js · Swiper 11 · Lenis · tsParticles 2.12 ·
Vanilla Tilt 1.8 · Font Awesome 6.4 · Google Fonts (Playfair Display + Inter)
