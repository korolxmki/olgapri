# Разбор портфолио (фото работ)

Скрипт превращает папку с фото работ в готовое портфолио по категориям, которое можно отправить ссылкой:
находит дубли, раскладывает по категориям **по содержимому фото**, даёт понятные латинские имена,
делает облегчённые копии и пишет отчёт.

## Как запустить (Windows)

1. Скопировать эту папку (`portfolio_sort.py`, `run.ps1`, `requirements.txt`) в
   `C:\Users\Sasha\Jarvis\фото мебель\_служебное\`.
2. В PowerShell:
   ```powershell
   cd "C:\Users\Sasha\Jarvis\фото мебель\_служебное"
   powershell -ExecutionPolicy Bypass -File .\run.ps1
   ```
   Первый запуск ставит библиотеки в `_служебное\venv` (~1 ГБ) и скачивает модель распознавания
   в `_служебное\models` (~1.7 ГБ). Анализ на обычном ноутбуке — примерно 1–2 секунды на фото;
   промежуточные результаты кэшируются, повторный запуск быстрый.

Нужен Python 3.10+ (`winget install Python.Python.3.12`, если его нет).

## Что получится

```
Jarvis\
  Портфолио\                  ← это загружаем на Яндекс.Диск
    Кухни\  Шкафы\  Прихожие\  Ванные\  Гардеробные\  Тумбы\  Проекты квартир\
    ОТЧЁТ.txt                 ← перед отправкой ссылки клиентам лучше убрать
  фото мебель\                ← оригиналы, не изменены
    _дубли\группа-NNN\        ← перенесённые дубли (не удалены)
    _разобрать\               ← копии фото, которые не удалось отнести к категории + список.txt
    _служебное\
      разметка.csv            ← всё по каждому файлу: категория, новое имя, дубль чего, проблемы
      проверка.html           ← все фото миниатюрами по категориям — быстро проверить глазами
      ОТЧЁТ.txt, перемещения.jsonl, кэш, модель, venv
```

Копии в Портфолио: длинная сторона ≤ 2000 px, JPEG 85, sRGB, без EXIF/GPS.

## Как поправить результат

1. Открыть `_служебное\проверка.html`, найти ошибки.
2. В `_служебное\разметка.csv` (открывается в Excel) поменять колонку **категория** (`Кухни`, `Шкафы`,
   `Прихожие`, `Ванные`, `Гардеробные`, `Тумбы`, `Проекты квартир` или `_разобрать`) и при желании
   **описание** (латиница через дефис: `belaya-uglovaya`). Чтобы убрать фото из Портфолио —
   статус `исключить`.
3. `.\run.ps1 apply` — Портфолио пересоберётся, имена перенумеруются. Старые копии, которых больше
   нет в разметке, не удаляются, а уезжают в `_служебное\старые-версии\`.

Вернуть дубли на исходные места: `.\run.ps1 undo`.

## Как это работает

- **Дубли.** Точные — по SHA-256. Похожие: кандидаты по perceptual hash (все 4 поворота) и по смысловой
  близости CLIP; затем проверка «тот же кадр»: ORB-точки сходятся через поворот/масштаб/сдвиг, один кадр
  почти целиком лежит в другом, а после совмещения совпадают мелкие детали. Ловит кроп, пережатие,
  уменьшение, поворот, правку яркости; разные ракурсы одной мебели дублями не считаются.
  В группе остаётся фото с наибольшим разрешением, затем самое тяжёлое (меньше сжатие).
- **Категории.** Нейросеть CLIP (ViT-L-14, локально, без интернета после скачивания) сравнивает фото
  с описаниями категорий и «не-мебели» (скриншоты, документы, чертежи, люди, мастерская, крупные
  планы деталей, другая мебель). Уверенность < 45% или две почти равные категории → `_разобрать`.
- **Имена.** `категория-цвет-тип-отделка-NN.jpg`, например `kuhnya-belaya-uglovaya-01.jpg`. Слово
  пишется, только если модель в нём уверена; нумерация по дате съёмки.
- **Проблемы.** Битые файлы, тёмные, размытые (по самому резкому участку кадра), низкое разрешение — в отчёте.

## Как проверялось

На тестовой папке из 75 файлов: открытые фото интерьеров с Wikimedia Commons, четыре фото с сайта и
подготовленные ловушки (точная копия, пережатая уменьшенная копия, два кропа, поворот пикселями,
поворот через EXIF, PNG- и HEIC-копии, обрезанный и мусорный `.jpg`, тёмное, размытое и маленькое фото,
видео, `Thumbs.db`, кириллица в именах, вложенные папки).

- Дубли: найдены 10 из 10. Ложных склеек нет: две половины одного кадра и два ракурса одного зала
  остались разными.
- Категории: 54 из 60 совпали с ручной разметкой. Расхождения спорные и для человека: старинные гравюры
  ванной и прихожей, парадный вход, крупный план угла столешницы, размытая гардеробная.
- Цвет в имени: ошибок нет; цвет пишется, только когда модель уверена.
- Повторный `run` даёт тот же результат. Ручная правка разметки (включая опечатку в категории и
  описание кириллицей) работает. После `undo` оригиналы побайтно совпадают с исходными.
